# 🐍 Ekosistem Python & Dasar Analisis Data untuk Data Science

Modul kedua ini berfokus pada pengenalan ekosistem perangkat lunak (*software ecosystem*) di Python, penguasaan struktur data fundamental, manipulasi data tabular menggunakan **Pandas**, serta teknik awal pembersihan data dan visualisasi statistik menggunakan **Matplotlib** dan **Seaborn**.

---

## 📂 Struktur & Materi Pembelajaran

1. **Ekosistem Perangkat Lunak:** Memahami peran Python, keunggulan *open-source*, serta fungsi dari empat pustaka inti: **NumPy**, **Pandas**, **Matplotlib**, dan **Seaborn**.
2. **Lingkungan Kerja:** Penggunaan **Jupyter Notebook** (via Anaconda) dan **Google Colab**, pembedaan sel *Code* vs *Markdown*, serta verifikasi instalasi pustaka.
3. **Dasar-Dasar Python:** Penggunaan *List*, *Dictionary*, serta pengenalan konsep *vectorization* pada **NumPy Array**.
4. **Pandas (DataFrame & Series):** Memahami struktur data tabel dua dimensi, membangun DataFrame secara manual, serta memuat data eksternal berformat CSV (`pd.read_csv`).
5. **Inspeksi Data Mendalam:** Menggunakan fungsi `head()`, `tail()`, `shape`, `info()`, `describe()`, hingga penghitungan frekuensi kategori (`value_counts()`) dan pengukuran *missing value* (`isnull().sum()`).
6. **Penanganan Missing Value Sederhana:** Menerapkan strategi penghapusan (*deletion*) dan imputasi data kosong (menggunakan konstanta, median, atau *forward fill*).
7. **Visualisasi Data Dasar:** Membuat dan menginterpretasikan **Histogram** (distribusi data), **Boxplot** (deteksi *outlier* via IQR), **Scatter Plot** (hubungan antar variabel), serta **Heatmap Korelasi**.
